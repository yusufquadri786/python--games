# CyberShield — Password Security Analyzer

A beginner-friendly, local-only password-pattern analyzer built with Python and Tkinter.

## Features
- Simple desktop GUI
- Educational score and improvement tips
- Flags repeated characters and common predictable fragments
- No external dependencies
- Does not save or transmit the entered text

## Important privacy note
For learning, enter a made-up sample rather than a real password. This tool uses basic heuristics and cannot guarantee that a password is secure.

## Requirements
- Python 3.10 or newer
- Tkinter (usually included with standard Python on Windows)

## Run on Windows
1. Download `cybershield.py` from this repository.
2. Open a terminal in the downloaded folder.
3. Run:

```powershell
py cybershield.py
```

## Learning goals
- Python functions and regular expressions
- Basic GUI programming with Tkinter
- Password hygiene and local data handling

## Responsible use
This project is for education and defensive security. It does not attempt to log in to accounts, test passwords against websites, or collect credentials.
